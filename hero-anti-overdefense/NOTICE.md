# Provenance and license

## Source

`SKILL.md` packages the English rule block from HERO - Anti-OverDefense without changing its rules or calibration examples. The only addition is the Agent Skills frontmatter required for discovery and triggering.

The full case catalogue is intentionally not bundled. Upstream states that it should not be loaded into every agent session because mechanical example matching can suppress real findings.
